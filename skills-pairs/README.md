# Generated pair skills for the `dlake` CLI

Two families. **CRMPro** (forward sync): one skill per **ERP × CRM pair** that ships a Standard CRMPro template set, generated from the shipped template
catalogue. Each page states only what its pair's templates set up — the process rows, the views and how each
detects change, the repository key, the order of work, the field mapping and the business outcome of each
template group — and defers to its parent, [`skills/dlake-crmpro/SKILL.md`](../skills/dlake-crmpro/SKILL.md),
for the tools, the tables and the engine behaviour. Where a hand-written destination skill exists
(`dlake-crmpro-hubspot`, `dlake-crmpro-syspro-salesforce`, `dlake-crmpro-syspro-shopify` under `skills/`),
the pair page names it too. Pages describe Standard templates only and quote no template SQL.

These pages are **not bundled in the CLI** and `dlake skills install` does not install them. Fetch the one you
need: copy its folder into your harness's skills directory, or read it here. Every page carries
`generated: true` and a marker comment; a hand-edit promotes a page to hand-written status and it is then
reviewed line by line. The pages grow as the catalogue does; a thin page reflects a thin template set.


One row per generated page, in the style of the **Available skills** table in
`publishing/dlake-cli/skills/README.md`, grouped by destination. Each page is generated from the
shipped template catalogue and extends `dlake-crmpro/`; the hand-written destination pages
(`dlake-crmpro-hubspot/`, `dlake-crmpro-syspro-salesforce/`, `dlake-crmpro-syspro-shopify/`) keep their
own rows and are not repeated here.
