# Agent skills: public capability summaries

The skills in this folder are **capability summaries**. Each one says what a Commercient integration does
for the business and who can get the operating guide; none of them is an operating guide.

The operational skills are published on the Commercient admin plane. Registered, whitelisted Commercient
customers fetch them with `dlake admin get_skill <name>`, where `<name>` is the folder name here, or list
them with `list_skills`.

- Existing customers who need access or help: support@commercient.com.
- New customers: sales@commercient.com, to become a customer and be whitelisted.

`dlake skills install` writes these summaries into your agent's skills directory.
