# CRMPro → Shopify — Sage 100 2018: what the shipped templates set up

This is a capability summary, not an operating guide. To receive the operational skill you must be a
registered, whitelisted Commercient customer. Whitelisted customers fetch it with
`dlake admin get_skill dlake-crmpro-shopify/erps/sage-100-2018` (or `list_skills`) against the
Commercient admin plane. Existing customers who need access or help: contact
support@commercient.com. New customers: contact sales@commercient.com to become a customer and be
whitelisted.

dlake-crmpro is the parent skill and the authority for everything general: the CRMPro tools, process
configuration and field list, the sync history, how source data is selected, and what a run that
finds nothing does. Read it first; this page does not repeat it. dlake-crmpro-shopify is the
destination skill this page is a child of, and the authority for the Shopify conventions that hold
across every ERP: read it first, then come back here for what this source's own templates set. This
page grows as the catalogue does.

## 1. What the templates deliver

| Group | Business outcome | Objects | Source tables and views |
|---|---|---|---|
| **Create Customer** | The templates push Customer to Shopify. | Customer | customers |
| **Create Customer Address** | The templates push Customer address to Shopify. | Customer address | countries, customers |
| **Create Product** | The templates push Product object to Shopify. | Product object | items |
| **Create Order** | The templates push Order to Shopify. | Order | countries, sales order headers, customers, sales order history headers |
| **Create Order Shipping Address** | The templates push Order shipping address to Shopify. | Order shipping address | countries, sales order headers, customers, sales order history headers |
| **Create Order Billing Address** | The templates push Order billing address to Shopify. | Order billing address | countries, sales order headers, customers, sales order history headers |
| **Create Order Line Item** | The templates push Order line item to Shopify. | Order line item | sales order lines, sales order headers, sales order history lines, sales order history headers |
| **Product object update** | The templates push Product quantity, Product price to Shopify. Existing records are updated only — nothing is created and nothing is deleted. | Product quantity, Product price | items, Shopify product variants (mirrored), Shopify inventory levels (mirrored) |

## 4. Order of work

The templates set run sequence to 1, 2, 3, 5, 6, 7, 8. A run processes active rows in ascending run
sequence, which is the order the templates put them in:

- 1 — Create Customer, Update Quantity, Update Price
- 2 — Create Customer Address
- 3 — Create Product
- 5 — Create Order
- 6 — Create Order Shipping Address
- 7 — Create Order Billing Address
- 8 — Create Order Line Item

Several of these rows share a run sequence value: each template group carries its own numbering, so
give the imported processes an order across the whole set rather than taking the template values as
one.

These views read another process's sync output, which is what makes the order a dependency order:
the row appears in the view only once the process that writes that sync output has run, so a parent
flows on one run and its children on the next.

- new customer address feed reads new customer sync output
- new order feed reads new customer sync output
- new order shipping address feed reads new order sync output
- new order billing address feed reads new order sync output
- new order line item feed reads new order sync output, new item sync output, new item variant sync
  output; no template in this set writes new item variant sync output

## 7. Where this sits

dlake-crmpro is the general operating surface — the CRMPro tools, the setup and transaction tables,
field mapping, and the source view contract that applies to every destination. This page adds what
the shipped Sage 100 2018 → Shopify templates set up. dlake-crmpro-shopify is the destination skill
this page sits under: its own text is the authority for the Shopify conventions that hold across
every ERP, and its ERP table lists this page alongside every sibling ERP page for this destination.

runs it, dlake-syncagent; for the writeback leg, dlake-txdownloaderpro; for standing an integration
up, dlake-integration-setup.
