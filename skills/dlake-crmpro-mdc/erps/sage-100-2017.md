# CRMPro → MDC — Sage 100 2017: what the shipped templates set up

This is a capability summary, not an operating guide. To receive the operational skill you must be a
registered, whitelisted Commercient customer. Whitelisted customers fetch it with
`dlake admin get_skill dlake-crmpro-mdc/erps/sage-100-2017` (or `list_skills`) against the
Commercient admin plane. Existing customers who need access or help: contact
support@commercient.com. New customers: contact sales@commercient.com to become a customer and be
whitelisted.

dlake-crmpro is the parent skill and the authority for everything general: the CRMPro tools, process
configuration and field list, the sync history, how source data is selected, and what a run that
finds nothing does. Read it first; this page does not repeat it. dlake-crmpro-mdc is the destination
skill this page is a child of, and the authority for the MDC conventions that hold across every ERP:
read it first, then come back here for what this source's own templates set. This page grows as the
catalogue does.

## 4. Order of work

The templates set run sequence from 22 to 31. A run processes active rows in ascending run sequence,
which is the order the templates put them in:

- 22 — sales order
- 23 — sales order detail
- 24 — invoice
- 25 — invoice detail
- 26 — quote
- 27 — quote detail
- 28 — Sage 100 2017 Sales order
- 29 — Sage 100 2017 Sales order Detail
- 30 — Sage 100 2017 Invoice
- 31 — Sage 100 2017 Invoice Detail

These views read another process's sync output, which is what makes the order a dependency order:
the row appears in the view only once the process that writes that sync output has run, so a parent
flows on one run and its children on the next.

- sales order feed (standard objects) reads AR customer, CRM account sync output (alternative
  generic name), sales order sync output (standard objects); no template in this set writes AR
  customer, CRM account sync output (alternative generic name), sales order sync output (standard
  objects)
- sales order line feed (standard objects) reads CRM account sync output (alternative generic name),
  Sage 100 product sync output, sales order sync output (standard objects), sales order line sync
  output (standard objects); no template in this set writes CRM account sync output (alternative
  generic name), Sage 100 product sync output, sales order sync output (standard objects), sales
  order line sync output (standard objects)
- invoice feed (standard objects) reads AR customer, CRM account sync output (alternative generic
  name), invoice sync output (standard objects); no template in this set writes AR customer, CRM
  account sync output (alternative generic name), invoice sync output (standard objects)
- invoice line feed (standard objects) reads invoice sync output (standard objects), CRM account
  sync output (alternative generic name), Sage 100 product sync output, invoice line sync output
  (standard objects); no template in this set writes invoice sync output (standard objects), CRM
  account sync output (alternative generic name), Sage 100 product sync output, invoice line sync
  output (standard objects)
- quote line feed (standard objects) reads CRM account sync output (alternative generic name), Sage
  100 product sync output, quote sync output (standard objects), quote line sync output (standard
  objects); no template in this set writes CRM account sync output (alternative generic name), Sage
  100 product sync output, quote sync output (standard objects), quote line sync output (standard
  objects)
- sales order feed (Commercient objects) reads AR customer, CRM account sync output (alternative
  generic name), sales order sync output (Commercient objects); no template in this set writes AR
  customer, CRM account sync output (alternative generic name), sales order sync output (Commercient
  objects)
- sales order line feed (Commercient objects) reads CRM account sync output (alternative generic
  name), Sage 100 product sync output, sales order sync output (standard objects), sales order line
  sync output (Commercient objects); no template in this set writes CRM account sync output
  (alternative generic name), Sage 100 product sync output, sales order sync output (standard
  objects), sales order line sync output (Commercient objects)
- invoice feed reads AR customer, CRM account sync output (alternative generic name), invoice sync
  output; no template in this set writes AR customer, CRM account sync output (alternative generic
  name), invoice sync output
- invoice line feed (Commercient objects) reads invoice sync output (standard objects), CRM account
